Commandes

Le site permet de composer un panier puis de préparer un message de commande, envoyé via WhatsApp. Une commande n'est confirmée qu'après la réponse de la pâtisserie. Les prix sont indiqués en francs CFA (FCFA) ; la disponibilité, les délais et les frais de livraison sont confirmés lors de l'échange. Le mode de paiement souhaité (espèces, TMoney ou Flooz) est transmis dans le message, mais aucun paiement n'est effectué sur le site ; les modalités sont confirmées avec la pâtisserie.

Données personnelles

Ce site n'a ni serveur ni base de données. Le contenu de votre panier est conservé uniquement dans votre navigateur (stockage local) et disparaît si vous effacez les données de navigation. Les informations saisies dans le formulaire de contact ne sont pas enregistrées par le site : elles servent à préparer un message que vous envoyez vous-même via WhatsApp, dont les conditions d'utilisation s'appliquent. Les polices de caractères sont chargées depuis Google Fonts, ce qui transmet votre adresse IP à ce service.

Pour toute question sur vos données : contact à compléter.
